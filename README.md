# Semana de Arte Moderna — museu virtual

Projeto interativo em Unity 2022.3.62f1. Abra `UnityProject/Assets/Scenes/MuseumScene.unity`
e pressione Play para visitar o museu com fichas automáticas por olhar.

Consulte [instruções de visita e manutenção](UnityProject/README.md).

Para jogar com celular Android em visor VR Box, consulte o
[guia de preparação e controles pelo olhar](UnityProject/VR_BOX.md).

O ambiente possui galerias inspiradas no Louvre, com arcos, cúpula, lustre e parquet.
Veja o [redesign e as capturas reais](artifacts/LOUVRE_REDESIGN.md).
